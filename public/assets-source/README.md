# Owner Assets Source (`/public/assets-source/`)

This directory is reserved exclusively for authentic source assets supplied by **Ansh Kumar Singh**.

## Instructions for Owner:
1. Place your final high-resolution renders, clay passes, wireframes, and video turntable clips here.
2. For 3D models, place Draco or Meshopt-compressed `.glb` files into `/public/models/`.
3. When adding any asset, update its entry in `src/data/projects.ts` and ensure its license is listed in `src/data/assets-licenses.ts`.
4. Run `npm run test:budgets` to confirm your models and images comply with the documented asset budgets (`docs/asset-budgets.md`).
