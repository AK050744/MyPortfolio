# Asset Budgets & Performance Rules

This document specifies the non-negotiable size, polygon, and network budgets for **Ansh Kumar Singh's 3D Artist Portfolio**. All assets included in `public/` and `src/data/` must adhere to these limits.

---

## 1. Media Asset Budgets

| Asset Type | Maximum File Size | Recommended Formats | Compression / Optimization Strategy |
| :--- | :--- | :--- | :--- |
| **Hero Background Video** | **≤ 6.0 MB** | MP4 (H.264, CRF 26) + WebM (VP9) | 1080p, 24fps, muted, no audio stream, ≤ 15s duration |
| **Hero Poster Image** | **≤ 300 KB** | WebP / AVIF (Q82) | High-resolution still frame, preloaded with `<link rel="preload">` |
| **Grid Thumbnails** | **≤ 120 KB** | WebP / AVIF (Q80) | Aspect ratio 16:9 or 4:3, explicit `width` and `height` attributes |
| **Hover Preview Video** | **≤ 1.5 MB** | MP4 / WebM (no audio) | 480p, 24fps, ≤ 4s loop, loaded on hover/focus only |
| **Final Render Gallery** | **≤ 800 KB** (standard) / **≤ 4.0 MB** (full-res) | WebP / AVIF | Standard view lazy-loaded; full-resolution loaded on lightbox zoom |
| **WIP Clay / Wireframes** | **≤ 450 KB** | WebP / AVIF | High clarity, progressive encoding |

---

## 2. 3D Model (GLB) Budgets (for "View in 3D")

The 3D viewer is strictly **opt-in**. No 3D model or Three.js engine code is fetched until the visitor clicks **"View in 3D"**.

| Metric | Budget Limit | Validation Check |
| :--- | :--- | :--- |
| **GLB File Size** | **≤ 5.0 MB** | Draco or Meshopt compressed binary |
| **Triangle Count** | **≤ 150,000 triangles** | Evaluated via `geometry.index` / vertices |
| **Texture Dimensions** | **≤ 2048 × 2048 px** | Basisu / KTX2 or compressed PNG/JPG |
| **Draw Calls** | **≤ 25 per model** | Consolidated materials and mesh instancing |
| **License Record** | **Required** | Must have valid entry in `src/data/assets-licenses.ts` |

---

## 3. JavaScript & Runtime Budgets

| Metric | Target Budget | Strategy |
| :--- | :--- | :--- |
| **Initial Client JS (First Paint)** | **≤ 150 KB gzip** | Pure static HTML generated by Astro; zero unnecessary JS |
| **Three.js Core & Loaders** | Lazy-loaded chunk | Dynamically imported only after "View in 3D" button activation |
| **Max Frame Render Time** | **< 16.6ms (60 FPS)** | `requestAnimationFrame` throttled, render on-demand upon interaction |
| **Max Pixel Ratio** | `min(window.devicePixelRatio, 2.0)` | Capped at 1.5 on coarse/mobile viewports to prevent GPU thermal throttling |
| **Memory Disposal** | Zero leaks | Comprehensive `dispose()` calls on unmount and context destruction |

---

## 4. Accessibility & Network Mode Restrictions

1. **`prefers-reduced-motion: reduce`**:
   - Hero video does NOT autoplay; the static hero poster is rendered.
   - Hover video previews are disabled.
   - 3D model auto-rotation is disabled; manual keyboard and pointer orbit remain active.
2. **`Save-Data: on`**:
   - Video autoplay disabled globally.
   - 3D models load only with explicit secondary user confirmation.
   - WebGL background canvas is disabled.
